'cronheart': minor

`cronheart sync --print-env` and `envLinesFor` write a line only for a monitor whose returned identifier is an identifier, and the command names the monitors it left out on stderr. A refusal of `--uuid` cuts an identifier that came behind or in front of an invisible character, or inside an address or a crontab line, and says that an invisible character came with it; `cronheart sync --print-env` exits with a problem status when it left a monitor out. The plan prints the zone, the schedule kind and the channel kind the service returned with their unprintable code points spelled out, and cuts a channel label that is an identifier; a name the plan prints is cut when it holds an identifier anywhere. The set of code points spelled out is the Unicode default-ignorable code points and space separators, with the blank Braille pattern U+2800 and U+FFF9 to U+FFFB, which adds among others U+00AD, U+034F, U+180B to U+180F, U+2065 to U+206F, U+3164, U+FE00 to U+FE0D and U+FFA0; U+200C, U+200D, U+FE0E and U+FE0F stay readable so emoji names print whole. A cron alias is matched in ASCII case only in the management client, in sync and in the scheduler adapters, so a schedule written with the Kelvin sign U+212A in place of a k is refused as an unknown alias rather than taken for `@weekly`.
